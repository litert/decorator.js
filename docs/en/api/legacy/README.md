# Module `Legacy`

Helpers for Stage 2 experimental decorators (TypeScript with `experimentalDecorators` enabled). Includes support for parameter decorators, which have no equivalent in the modern standard.

Import this module from `@litert/decorator/legacy`.

[TOC]

## Import

```ts
import * as Decorators from '@litert/decorator/legacy';
```
